# IBM-HR-Analysis-Dashboard
Project Overview

This project is an interactive IBM HR Analytics Dashboard created using Power BI and SQL. The dashboard helps analyze employee data, attrition trends, job satisfaction, and workforce performance to generate useful HR insights.

Objectives
* Analyze employee attrition
* Understand workforce trends
* Track employee performance and satisfaction
* Identify departments with high attrition
* Generate HR insights using data

Tools & Technologies Used
* Power BI
* SQL / PostgreSQL
* Excel / CSV Dataset

Dashboard Features
* Total Employees KPI
* Attrition Rate Analysis
* Department-wise Employee Distribution
* Gender & Age Analysis
* Job Satisfaction Insights
* Salary Analysis
* Overtime vs Attrition
* Interactive Filters & Slicers

Skills Demonstrated
* Data Cleaning
* Data Analysis
* Data Visualization
* SQL Query Writing
* Dashboard Design
* HR Analytics
* Business Insights

Business Insights
* Identified departments with high attrition
* Analyzed employee satisfaction trends
* Found relationship between overtime and attrition
* Compared workforce distribution across departments

Dataset Source

Dataset collected from publicly available HR analytics datasets for learning and analytical purposes.
Source: Kaggle
